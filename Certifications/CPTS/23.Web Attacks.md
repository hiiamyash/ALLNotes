# Intro to HTTP Verb Tampering

- **HTTP Verbs**: Methods like `GET` or `POST` used at the start of a request to define an action.
- **Method Testing**: While apps usually expect `GET`/`POST`, clients can send others (e.g., `HEAD`, `PUT`) to see how the server responds.
- **Proper Configuration**: Secure servers restrict methods to only what's needed, showing an error page for others.
- **Insecure Configuration**: If not restricted, attackers can exploit unhandled methods to bypass security controls or access hidden features.

---

## Common HTTP Verbs

Beyond `GET` and `POST`, there are several other [HTTP verbs](https://developer.mozilla.org/en-US/docs/Web/HTTP/Methods):

| Verb | Simple Explanation |
| :--- | :--- |
| `HEAD` | Like `GET`, but only returns headers (no body). |
| `PUT` | Uploads/Overwrites a file at a specific location. |
| `DELETE` | Deletes a resource at a specific location. |
| `OPTIONS` | Lists which HTTP methods the server supports. |
| `PATCH` | Applies partial updates to a resource. |

**The Risk**: If methods like `PUT` or `DELETE` are enabled without security, attackers can modify or delete files on the server.

---

## Insecure Configurations

Vulnerabilities often occur when authentication is only applied to specific methods.

**Example**:
```xml
<Limit GET POST>
    Require valid-user
</Limit>
```
- **The Flaw**: This only protects `GET` and `POST`.
- **The Attack**: An attacker could use `HEAD` or another method to bypass the login and access the page.

---

## Insecure Coding

This happens when security filters don't cover all input types.

**Example**:
```php
if(preg_match($pattern, $_GET["code"])) {
    $query = "... " . $_REQUEST["code"] . " ...";
}
```
- **The Flaw**: The filter only checks `$_GET`, but the database query uses `$_REQUEST`.
- **The Attack**: `$_REQUEST` often includes both `GET` and `POST` data. An attacker can send a malicious `POST` parameter to bypass the `GET` filter and perform an attack like SQL Injection.

**Summary**: While server misconfigurations happen, coding errors (like inconsistent variable use) are more common.
